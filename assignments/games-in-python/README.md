
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir o clássico jogo da Forca em Python para praticar manipulação de strings, loops, condicionais e seleção aleatória.

## 📝 Tarefas

### 🛠️	Implementar o Jogo da Forca

#### Descrição
Desenvolva um programa em Python que selecione uma palavra aleatória e permita ao jogador adivinhar letras até descobrir a palavra completa ou ficar sem tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória a partir de uma lista predefinida.
- Aceitar palpites de letras e exibir o progresso atual da palavra no formato _ _ _.
- Rastrear e mostrar o número de tentativas incorretas restantes.
- Encerrar o jogo quando a palavra for totalmente adivinhada ou quando as tentativas acabarem.
- Exibir uma mensagem final de vitória ou derrota ao término da partida.
